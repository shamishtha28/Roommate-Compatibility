# RoomSync – Intelligent Roommate Compatibility & Conflict Prediction System

## Project Overview
RoomSync is an OOP-based project designed to evaluate lifestyle compatibility between two students who may share a room. It compares their preferences and calculates a compatibility score.

## Features
- Compare two students' lifestyle preferences.
- Calculate an overall compatibility percentage.
- Display category-wise compatibility.
- Identify potential differences and conflicts.
- Provide suggestions for managing differences.

## Preferences Considered
1. Sleep Schedule
2. Study Habit
3. Cleanliness
4. Noise Tolerance
5. Visitor Frequency

- `index.html` – Website structure
- `style.css` – Website styling
- `main_server.cpp` – C++ HTTP server and backend
- `org_main.cpp` – Original console-based OOP implementation

## How It Works
Two students enter their lifestyle preferences through the website. The C++ backend compares their preferences, calculates a compatibility score, identifies differences, and returns the results to the website.

## Project Objective
To help students understand potential roommate compatibility and encourage better communication before sharing a room.
